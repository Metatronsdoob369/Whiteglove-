## Contact Path Notes

**Cold outreach priority order:**
1. LinkedIn direct message to named buyer (personalized, no pitch in opener)
2. Email via org website contact / press@ forwarded to named buyer
3. Conference circuit: HIMSS, AMIA, ViVE — all three have active attendance from Tier 1-2 targets

**Leave-behind sequence:**
- Email 1: problem framing only, CTA = 20-min call
- Email 2 (day 3 follow-up): attach `11_whiteglove_executive_summary_healthcare_hipaa.md`
- Demo: use `02_whiteglove_demo_script.md`, close with Standard Pilot offer + start date

**Signals to watch for:**
- Recent AI governance announcement
- EHR migration in progress
- Joint Commission audit cycle
- New CMIO/CIO hire (first 90 days = best procurement window)
