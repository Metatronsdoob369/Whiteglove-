## 7) Daily Decision Gate

If **Reply Rate < 5%** for 2 consecutive days:
1. Rewrite first 2 lines of opener (keep CTA unchanged)
2. Tighten "why now" sentence by org
3. Shift next 10 sends toward Tier 3 fast-close targets

If **Positive->Demo < 40%**:
1. Improve CTA specificity (offer exact slots)
2. Shorten message length by 20-30%
3. Add one compliance proof line (audit/refusal behavior)

If **Demos booked = 0 by end of Day 3**:
1. Trigger warm-intro ask campaign (partners/advisors)
2. Move 30% of volume to LinkedIn + email combo
3. Escalate with executive one-liner follow-up from founder account
